### Project Description
The AI Advice Nurse is a medical chatbot designed to provide basic health 
guidance for people experiencing minor common illnesses or injuries. A user will be able to 
enter symptoms such as a headache, cough, sore throat, mild fever, allergies, stomach 
discomfort, or minor injury. 
The chatbot will analyze the user's description and may ask follow-up questions to better 
understand the situation. It will then provide general information about possible common causes, 
self-care recommendations, and basic medication information when appropriate. If the user's 
symptoms suggest a potentially serious condition, the chatbot will advise the user to contact a 
healthcare professional or seek urgent or emergency medical care. The system will clearly 
explain that its responses are for general informational purposes and are not a professional 
medical diagnosis. The web prototype will clearly state that this is an educational prototype not intended for clinical use.
